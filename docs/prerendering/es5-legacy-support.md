# Legacy (ES5) Support — Retired

The ES5 rendering engine was retired 2026-09-02. All hosts now render on the headless Chrome engine with full ES6/7+ support.

**No action required.** If a page renders differently than before, purge its cache — the new engine may produce different output for edge-case code. For questions, [contact support](https://ostr.io/support).
